# Sistema de Fila Hospitalar com Classificação de Risco

Trabalho de Estrutura de Dados: um pronto-socorro que atende o paciente mais
grave primeiro e, dentro do mesmo nível de risco, respeita a ordem de chegada,
usando 5 filas FIFO (uma por cor de risco).

**▶ Sistema online:** https://gabrielr0berto.github.io/Fila-Hospitalar---Trabalho-de-Estrutura-de-Dados/

| Tela | Arquivo |
|---|---|
| Início | [`FilaHospitalar/web/index.html`](FilaHospitalar/web/index.html) |
| 1 · Triagem | [`FilaHospitalar/web/triagem.html`](FilaHospitalar/web/triagem.html) |
| 2 · Fila e chamada | [`FilaHospitalar/web/fila-hospitalar.html`](FilaHospitalar/web/fila-hospitalar.html) |
| 3 · Painel da TV | [`FilaHospitalar/web/painel.html`](FilaHospitalar/web/painel.html) |
| Simulação de um plantão | [`FilaHospitalar/web/vitrine.html`](FilaHospitalar/web/vitrine.html) |
| Programa de terminal (Python) | [`FilaHospitalar/fila_hospitalar.py`](FilaHospitalar/fila_hospitalar.py) |

As três telas se comunicam entre si: abra-as em abas lado a lado no mesmo
navegador. A documentação completa está em
[`FilaHospitalar/README.md`](FilaHospitalar/README.md).
